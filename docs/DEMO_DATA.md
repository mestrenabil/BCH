# البيانات التجريبية

يوفّر قسم الإعدادات للمسؤول العام لوحة لإنشاء أو إعادة محتوى افتراضي لآخر ثلاث سنوات، أو إزالته لاحقاً.

## قواعد السلامة

- كل سجل قابل للإزالة يحمل مرجعاً يبدأ بـ `SEED-`.
- الإزالة لا تستعمل `deleteMany()` عاماً، بل تستهدف مراجع `SEED-` والعلاقات التابعة لها فقط.
- لا تنشئ عملية المنصة مستخدمين تجريبيين، ولا تحذف المستخدمين أو الأعوان أو الأحياء أو إعدادات الجماعات.
- إعادة الإنشاء idempotent: السجلات الموجودة لا تتكرر، والسجلات المحذوفة تُعاد بالمراجع نفسها.
- كل إنشاء أو إزالة عبر الواجهة يتطلب `requireAdmin()` ويسجّل في `ActivityLog`.

## السنوات

يحسب المسار `/api/demo-data` السنة الحالية وسنتين سابقتين عند كل تشغيل. مثال سنة 2026: `2024، 2025، 2026`.

## التغطية

تشمل البيانات التجريبية المترابطة الأقسام والتبويبات التالية:

- التدخلات والحملات والشكايات وأوامر العمل والمخزون والوثائق والملفات الموحدة.
- المراقبة الغذائية: المنشآت، التفتيش، البطائق الصحية، العينات، النتائج المخبرية، درجات الحرارة، تتبع المنتجات، حالات عدم المطابقة وزيوت القلي.
- الماء والتطهير: نقاط الماء، المسابح، القياسات، العينات وسلسلة نقلها، التفتيش، الإجراءات، التعقيم، الحوادث، خطط الطوارئ، المختبرات، البرامج، الأجهزة والمعايرة ومنشآت الصرف.
- الحيوانات الشاردة: البلاغات والمهام والحيوانات والمراكز والإيواء والنقل والتنبيهات الصحية والنفوق والنقط السوداء والشركاء والتعريف والرعاية والوجهة والمتابعة والحملات وحالات العض والتلقيح.
- الجنائز والمقابر، البيئة والمعاينات والمتابعات والبرامج، التوعية، والتراخيص والآراء واللجان.

لا تُنشأ سجلات صور تجريبية لأنها تتطلب ملفات فعلية في `storage/`؛ وتبقى إضافتها واختبارها عبر الرفع الحقيقي.

## التشغيل اليدوي

```powershell
$env:SEED_YEARS='2024,2025,2026'
$env:SKIP_SEED_USERS='true'
$env:DEMO_ACTION='seed' # أو remove
node scripts/seed-2025.cjs
```
